# Dev Lab

This repository is my personal dev lab — a space for studying core concepts, experimenting with ideas, and learning by building small, focused projects.

The goal is not polished products, but understanding how things work through hands-on exploration.

## Structure

Each folder represents a topic, technology, or experiment. Projects may vary in size and completeness.

## Notes

- Some projects are exploratory and may be unfinished.
- Code quality and approaches may evolve over time.
- This repo reflects learning in progress.
